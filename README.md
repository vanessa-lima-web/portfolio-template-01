# Portfólio Hacker / Dev — Template 2026

Template completo de portfólio com visual **cyber / hacker**, animações modernas e estrutura profissional para estudantes de **Sistemas para Internet**.

## Como usar

1. Abra a pasta `portfolio-hacker-dev`
2. Dê dois cliques em `index.html` ou rode um servidor local:
   ```bash
   # Com Python
   python -m http.server 3000

   # Ou com VS Code Live Server
   ```
3. Personalize:
   - Nome, bio e links no `index.html`
   - Cores e efeitos no `styles.css` (variáveis CSS no topo)
   - Textos do efeito de digitação no `script.js`

## Estrutura

```
portfolio-hacker-dev/
├── index.html      → Estrutura completa
├── styles.css      → Visual cyber + responsivo + animações
├── script.js       → Matrix, typing, menu, scroll reveal
└── README.md
```

## O que este template já tem

- Visual dark cyberpunk com neon (verde + cyan)
- Efeito Matrix no fundo
- Scanlines sutis
- Navbar fixa com blur
- Hero com glitch + typing effect + terminal decorativo
- Seção Sobre com card de informações
- Skills com tags interativas
- **Projetos com mockup de browser** (muito importante)
- Badges de tecnologias
- Botões GitHub + Live Demo
- Formulário de contato
- Totalmente responsivo (mobile first)
- Acessibilidade básica (`prefers-reduced-motion`)
- Animações de entrada no scroll

## Como apresentar seus projetos (padrão recomendado)

Para cada projeto use esta estrutura:

1. **Mockup de browser** com print ou preview
2. **Tipo** (Full-stack / Frontend / API)
3. **Título** claro
4. **Descrição curta** (problema → solução)
5. **Badges** das tecnologias
6. **Dois botões**:
   - `GitHub` → repositório
   - `Live Demo` → link online (Vercel/Netlify)

## Dicas para deixar o seu ainda melhor

- Troque os previews fake por screenshots reais dos seus projetos
- Coloque links reais do GitHub e das demos
- Adicione mais projetos conforme for criando
- Considere hospedar na Vercel (grátis e fácil)
- Compre um domínio `.dev` ou `.com.br` quando puder
